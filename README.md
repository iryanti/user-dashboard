# User Dashboard

A responsive user dashboard built with Next.js App Router, React Query, and Tailwind CSS.

## Features

- Users dashboard
- Search and sorting
- User detail page
- Activity overview
- Posts and tasks
- Responsive UI
- Loading and error states
- Unit testing with Jest and RTL

## Tech Stack

- Next.js
- TypeScript
- React Query
- Tailwind CSS
- Jest
- React Testing Library

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Available Scripts

Run tests:

```bash
npm test
```

Run lint:

```bash
npm run lint
```

Build project:

```bash
npm run build
```
